# Frontmatter Fields

## name
Skill identifier. kebab-case. Matches directory name exactly.

## description
Primary trigger mechanism. Include both what it does AND when to trigger.
Be pushy — counteract agent tendency to undertrigger.
Mention the map pattern and pointer syntax the skill enforces.
Example pattern: "Use this even when user doesn't say [skill name] explicitly but clearly needs it."

## compatibility
Required tools or dependencies. Rarely needed — omit unless the skill genuinely cannot run without a specific tool.
